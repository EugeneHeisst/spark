# Spark 0.4.1

- На Linux звук демонстрации собирается из потоков других приложений через PipeWire. Голоса собеседников и уведомления Spark исключены, при этом ведущий продолжает слышать звонок.
- Кнопка «Шумодав вкл./выкл.» теперь находится рядом с микрофоном в панели звонка. Настройка сохраняется и применяется без выхода из звонка; она также доступна в «Настройки → Голос и трансляция».
- Для демонстрации со звуком на Linux нужны PipeWire и утилиты pw-loopback, pw-dump, pw-link, pactl. Без них Spark показывает ошибку, а не передаёт звук звонка обратно.

Windows использует встроенное исключение собственного звука Chromium. Физические Windows-устройства и Wayland-портал требуют пользовательской проверки.
