# Spark 0.4.2

- Громкость участников открывается правой кнопкой по имени, аватару, камере или демонстрации участника. Меню содержит отдельные ползунки «Голос» и «Стрим» только выбранного человека.
- Постоянные панели громкости убраны из звонка. Уровни сохраняются отдельно для каждого участника и действуют только на вашем компьютере.
- Меню закрывается кликом снаружи или Esc и размещается внутри границ окна.
- Сохранены исключение собственного звука из демонстрации на Linux и кнопка «Шумодав».
