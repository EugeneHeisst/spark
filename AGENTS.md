# Spark — инструкции Codex

Сначала прочитай [CODEX_HANDOFF.md](CODEX_HANDOFF.md): это контекст проекта, стартовый промпт, команды и известные ограничения. Затем сверяй фактическое дерево, `git status` и текущую задачу пользователя; handoff описывает состояние на 2026-11-11.

- Общайся с пользователем по-русски. Проект — приватный LAN-мессенджер для Linux и Windows: Rust-сервис + Rust/WASM-интерфейс + тонкая оболочка Electron.
- Сохраняй готовые чаты, звонки, одновременные камеру/экран и передачу файлов. Не заменяй реальные проверки заглушками или декоративными кнопками.
- Исправления проверяй подходящими native/WASM/E2E-тестами. Физические Windows-захват, Wayland-портал и связь между ПК и ноутбуком ещё требуют проверки; не выдавай CI за такую проверку.
- Тесты камеры/экрана проводи на изолированном тестовом дисплее и синтетических устройствах. Не захватывай настоящий рабочий стол, не меняй системные сеть/прокси/брандмауэр/аудио/автозапуск без соответствующей задачи.
- Пользователь 2026-11-11 явно разрешил сделать `EugeneHeisst/spark` публичным; репозиторий теперь public. Разрешено публиковать готовые, проверенные релизы без повторного запроса. Не публикуй незавершённые сборки, секреты, профили пользователей или личные данные.
- Эта копия передана на ПК для дальнейшей работы. Копия на ноутбуке тоже существует; не придумывай политику синхронизации и не перезаписывай чужие изменения.
